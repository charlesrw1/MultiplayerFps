# Bike AI Test Modes

These modes let you drive one part of the bike AI by hand.

## Lateral Steer

Set the AI lateral target and watch it steer the course.

- `enable_course_boundary`: add a layer that stops steering from leaving the course.
- You can also set the AI distance from the wheel to watch braking and acceleration.

## Paceline

Set the AI paceline mode by hand.

## Wheel

Set which wheel the AI follows. You can also force the wheel.
